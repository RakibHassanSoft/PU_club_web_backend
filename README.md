# PUPC – Problem-Solving & Competitive Programming Platform (Backend Focus)  
 
## 🔗 Live Link  
[Visit PUPC](https://pucp.netlify.app/)  
 
## 📌 Description  
PUPC is a platform for students and enthusiasts to practice coding and track progress.  
I handled the entire backend development, designing a **modular, scalable architecture**  
with secure APIs and database integration to support the frontend and user functionality.  
 
## ✨ Key Backend Features  
- Modular backend architecture with Node.js and Express.js  
- REST API development for user management, problem tracking, and analytics  
- Integration with MongoDB for data storage and management  
- Secure JWT-based authentication and role-based access control (RBAC)  
- Real-time data handling for user progress and submissions  
- API validation, error handling, and performance optimization  
- Collaboration-ready code structure for future team expansion  
 
## 🛠️ Backend Tech Stack  
- Node.js & Express.js (Modular Architecture)  
- MongoDB (Mongoose ODM)  
- JWT Authentication & Role-based Access Control  
- Postman for API testing  
- Git & GitHub for version control  
- Modular folder structure for maintainability and scalability
